# 51 单片机智能小车

## 1. 项目目标

以 51 内核单片机（STC89C52 / AT89C52 一类）为核心，完成一台集循迹、避障、遥控于一体的小车，并把硬件资料、固件源码、测试调参与上位机工具统一在一个工程目录下管理。

计划覆盖的功能：

- 红外循迹：多路 TCRT5000 一类传感器巡线，支持直道、弧线与直角弯道
- 超声波避障：HC-SR04 测距，按距离分级减速、停车与转向绕障
- 遥控通道：红外遥控（NEC 编码）与蓝牙串口（HC-05 / HC-06）二选一或并行
- 舵机云台：SG90 一类舵机带动超声波探头左右扫描
- 人机交互：LCD1602 / OLED 显示状态，按键切换模式，蜂鸣器与 LED 指示
- 电机驱动：L298N 一类双 H 桥，PWM 调速 + 正反转控制

## 2. 当前阶段：仅工程骨架

本目录当前只包含**目录结构 + 中文说明文档**，用于先固定工程组织方式：

- 不含任何 `.c` / `.h` 功能实现代码
- 不含 Keil uVision 工程文件（`.uvproj` / `.uvopt`）

## 4. 各目录职责

| 目录 | 职责 | 典型内容 |
| --- | --- | --- |
| `docs/` | 项目级文档 | 系统设计、协议、调试记录 |
| `hardware/` | 硬件资料 | 原理图、PCB、器件手册、引脚分配 |
| `firmware/` | 固件源码 | 主程序、应用层、驱动层、公共代码、配置 |
| `tests/` | 测试与调参 | 台架记录、单模块验证、日志 |
| `tools/` | 上位机与配套工具 | 串口助手、遥控面板、协议文档 |
| `scripts/` | 自动化脚本 | 构建、打包、烧录 |
| `release/` | 版本发布 | 固件归档、发布说明 |

固件内部分层约定：`main` 只做初始化和主循环调度；`app` 负责模式与业务逻辑；`drivers` 只对外设寄存器/时序做封装，不掺业务；`common` 提供与硬件无关的工具函数；`config` 集中所有引脚与参数宏。

## 5. 后续开发顺序建议

1. **选型与接线定稿**：确定 MCU 型号、电机驱动、传感器数量，填写 `hardware/pinmap/` 引脚表，把引脚宏写进 `firmware/config/`。
2. **搭建最小工程**：在 `firmware/project/` 建 Keil C51 工程，仅包含 `main.c` + `common/delay`，确认能编译、能烧录、能跑主循环。
3. **逐个点亮外设**：按「LED/蜂鸣器 → 按键 → 电机 PWM → 红外循迹 → 超声波 → 显示屏 → 舵机 → 遥控/蓝牙」顺序，每完成一个就在 `tests/module/` 留验证工程或记录。
4. **应用层组车**：实现循迹、避障、遥控三种模式及模式切换，状态机与阈值参数放 `firmware/app/` 与 `config/`。
5. **调参与稳定性**：在 `tests/bench/` 记录不同地面、光照、供电电压下的参数，形成参数表。
6. **上位机与发布**：完成 `tools/host/` 串口工具，固件与工具版本归档到 `release/archive/`，发布说明写入 `release/notes/`。

## 6. 命名与编码约定

- 目录与文件名一律小写英文，单词间用下划线，例如 `motor_driver.c`、`hc_sr04.c`。
- 每个模块的 `.c` 与 `.h` 同名成对；头文件统一放 `firmware/include/`，实现放对应模块目录。
- 引脚、阈值、周期等常量只在 `firmware/config/` 定义，其他文件通过宏引用，禁止散落硬编码。
- 驱动层函数统一前缀，如 `motor_`、`tracking_`、`ultrasonic_`、`servo_`。
- 新增模块时同步更新本 README 的目录树与该目录的说明。

## 7. 方案说明与可调整项

本结构基于常见的 51 智能小车方案：

| 部件 | 常见选型 | 可替换方案 |
| --- | --- | --- |
| 主控 | STC89C52RC / AT89C52 | STC89C52、STC12C5A60S2（增强型 51） |
| 电机驱动 | L298N 双 H 桥 | TB6612FNG、L9110S、L293D |
| 循迹 | TCRT5000 红外对管（3～5 路） | 灰度传感器、CCD 循迹模块 |
| 测距 | HC-SR04 超声波 | SR04M 防水型、VL53L0X 激光 |
| 遥控 | 红外 NEC + HC-05/06 蓝牙 | 2.4G 遥控、WiFi 模块 |
| 云台 | SG90 舵机 | MG995、双轴云台 |
| 显示 | LCD1602 / 0.96 寸 OLED | 数码管、TFT |

若实际选型不同，只需在 `hardware/` 更新资料、在 `firmware/config/` 调整引脚宏，目录结构本身无需大改。
