## 1. 规则要点

### 1.1 赛道与比赛环境（光电组）

| 项目 | 规则原文要点 | 对方案的直接影响 |
| --- | --- | --- |
| 赛道形式 | 由宽度 18mm±3mm 的黑色胶带组成环路，铺设在白色背景布上 | 传感器按“白底黑线”标定，不能沿用上届蓝色背景的阈值 |
| 线形 | 赛道由折线线段组成，折线夹角不小于 90°，折线长度不小于 10cm | 主要为直线段 + 转角，前瞻不宜过长，必须处理 90° 折角 |
| 元素 | 直线、折线、十字交叉线、环岛；环岛为六边形，边长不小于 20cm | 需要十字直行与环岛绕行两种专门状态 |
| 邻道 | 两条相邻赛道之间的最小距离为 20cm | 传感器阵列宽度要小于该间距，避免看到隔壁赛道 |
| 背景 | 本届改为白色背景（上届为蓝色，见规则图 2 说明） | 白色背景反光更强，阈值和遮光要求更高 |

> 注意：规则正文写“赛道由折线线段组成”，但规则图 2 的上届赛道照片中，环岛和部分弯道的观感偏圆弧。方案按“折线 + 可能出现的缓弯”兼容设计，不把控制参数锁死为纯折线。

### 1.2 车模与电路限制

| 项目 | 规则原文要点 | 结论 |
| --- | --- | --- |
| 车模形式 | 形式不限，允许自制，允许舵机转向，允许增加负压风扇 | 可用自制车架、差速转向，不强制舵机 |
| 投影尺寸 | 不得超过 29.7×21.0cm（A4 纸大小），特殊情况由组委会裁定 | 含传感器支架、电池、接插件一起测量 |
| 车轮 | 数量不限；除不得自有粘性外形式不限 | 可用橡胶轮、万向轮、牛眼轮 |
| 电机 | 数量及型号不作限制 | 双电机差速可行 |
| 电源 | 电池供电，电压不得超过 24V DC | 3S 锂电 11.1V，留有充足余量 |
| 禁止 | 严禁使用往届智能汽车竞赛成套车模、往届信达杯成套车模或其它成套成品 | 车架、底盘必须自制，不能买整套竞赛车模 |
| 主控 | 型号不限，但不得使用成品开发板 | 不能用淘宝 51 开发板直接参赛 |
| 核心板 | 直插封装的主控芯片，核心板需自制；贴片封装可用仅含 CPU、晶振、复位的最小系统核心板 | STC89C52RC 为 DIP-40，核心板必须自制 |
| 主板 | 必须自制；信息学院大二及以上需自制 PCB，其他学生可用洞洞板 | 本方案直接做自制 PCB，覆盖所有年级 |
| PCB 标识 | 铜层（不得只印丝印层）印参赛队员姓名、队伍名、制作时间；装车后难查验需提供同版本空板 | 主板、传感器板、驱动板都要印；各留一块空板 |
| I/O 引出 | I/O 信号需从自制主板上引出，不得直接从核心板引出 | 所有接插件放主板，核心板只做最小系统 |
| 电机驱动 | 信息学院大二及以上需自制电机驱动板，其他学生可用成品电机驱动 | 自制 TB6612 驱动板可拿“−5s”，建议统一自制 |
| 传感器板 | 光电组及电磁组的传感器电路板需自制，不得使用成品模块 | 不能买成品灰度模块/循迹模块，必须自己画板焊接 |
| 辅助传感器 | 超声波、TOF、IMU 等避障及姿态辅助传感器可使用成品 | 可用但本方案不依赖 |

### 1.3 比赛流程与计时判罚

| 项目 | 规则原文要点 | 方案对应 |
| --- | --- | --- |
| 出场 | 抽签决定出场顺序 | 赛前按抽签时间倒排热身 |
| 封存 | 赛前指定时间上交车模封存、检查、编号、贴主控芯片封存标识（电池可带走） | 封存前完成最终烧录和参数固化 |
| 资格 | 上交车模时需展示本队完赛视频；漏掉或主动放弃某些元素但仍能跑完的视同完赛 | 必须提前录制完整两圈视频 |
| 时间 | 每队比赛时间 5 分钟，自进入赛道开始计时，发车次数不限 | 允许多次试跑，策略上先稳后快 |
| 人员 | 场地内除裁判和一名队员外不允许其他人员进入 | 只留一名操作手 |
| 接触与遥控 | 发车后不得接触车模，更不能遥控；异常收回需示意裁判并获许可，同时本次成绩无效 | 比赛时物理断开蓝牙，起跑只用车上按键 |
| 有效发车 | 比赛时间内完成发车的成绩视为有效 | 最后一次发车也要留足时间 |
| 问辩 | 获奖队员需参加赛后问辩，无明显贡献或对工作不熟悉者取消获奖资格 | 每人必须能讲清自己负责的模块 |

### 1.4 计时、判罚与无效判定

| 项目 | 规则原文要点 | 量化影响 |
| --- | --- | --- |
| 圈数 | 车模需在指定赛道上连续运行两圈并自主停车 | 两圈 + 停车是完整任务 |
| 计时基准 | 以车模上同一位置（一般为车头）越过发车线作为开始及停止计时的依据 | 车头过线开始/结束，车上计时只用于自身策略 |
| 脱线 | 光电组：所有车轮均位于循迹线同侧 1s 以上，判定当次成绩无效，需重新发车 | 丢线保护必须在 1s 内停车 |
| 无法循迹 | 抵达终点前停止运行或循迹异常 5s 以上，判定当次成绩无效 | 卡死/原地打转要快速识别 |
| 停车 | 完成两圈后在发车线 +50cm 范围内自主停车（可越过发车线，不得提前停车）为有效；未能自主停车或手动停车 +20s | 目标停在过线后 20～35cm |
| 环岛 | 每漏过一次环岛 +30s | 一次漏环岛≈半圈时间，优先级高于提速 |
| 十字 | 每错误驶过一次十字 +30s | 十字必须直行，不能转向 |
| 自制驱动 | 光电组使用自制电机驱动（符合自制电路要求）参赛，成绩 −5s | 自制 TB6612 板值得做 |
| 无效 | 脱线、无法循迹等当次成绩无效，需重新发车 | 5 分钟内可重发，但不要浪费次数 |

**成绩模型：**

```text
T_最终 = T_两圈 + 20×I(停车失败) + 30×N(漏环岛) + 30×N(错十字) − 5×I(自制驱动)
```

结论：一次漏环岛或错十字的 30s 罚时，远大于把两圈从 55s 提到 45s 的收益。方案必须“稳定优先、罚时为王”，先把十字/环岛/停车做到高成功率，再提速。

### 1.5 允许与禁止的技术手段（光电组）

| 允许 | 禁止/高风险 |
| --- | --- |
| 自制车模、自制车架 | 往届智能汽车竞赛成套车模、往届信达杯成套车模、其它成套成品 |
| 舵机转向、负压风扇 | 成品开发板作为主控板 |
| 任意数量/型号电机 | 直插主控使用成品核心板（STC89C52RC 必须自制核心板） |
| 麦克纳姆轮、全向轮、万向轮、牛眼轮 | 光电组使用成品传感器模块（灰度、循迹模块等） |
| 3S/6S 等 ≤24V 电池 | 成品主板、非自制 PCB（大二及以上） |
| 自制电机驱动（−5s） | 发车后接触车模或遥控 |
| 成品超声波/TOF/IMU 作为辅助 | 镜头组使用电磁传感器（与光电组无关，但不要混装） |
| 自制传感器板（TCRT5000、比较器、移位寄存器） | 用摄像头成品模块替代光电循迹（规则未明确允许，按保守处理不用） |

### 1.6 规则中不明确、需要赛前确认的点

1. **多次发车取哪次成绩**：规则只说“比赛时间内完成发车的比赛成绩视为有效”，未写明取最好一次、最后一次还是平均。
2. **环岛的通过判定**：进入方向、绕行方向（顺时针/逆时针）、是否必须完整绕行一圈，均未写明；“每漏过一次环岛”按每圈计还是按每次经过计也不明确。
3. **十字“错误驶过”的定义**：是否允许在十字处转向、是否必须直行、判罚按每次经过还是每圈计，未写明。
4. **发车线的形式与位置**：是否为一条横跨赛道的黑线、线宽多少、是否与某个十字重合；“发车线 +50cm”是从线中心还是线边缘算，未写明。
5. **脱线判定的“同侧”基准**：以车体中心、车头还是任一参考点判定“所有车轮位于循迹线同侧”，1s 是否要求连续，未写明。
6. **投影尺寸测量状态**：静态测量还是运行状态、是否包含传感器支架/风扇/线缆，未写明。
7. **相邻赛道 20cm 的定义**：边到边还是中心线到中心线，未写明；直接影响传感器阵列最大宽度。
8. **赛道总长与元素位置**：只给了元素尺寸下限，未给赛道总长、环岛数量/位置、十字数量；赛前是否公布赛道图未说明。
9. **单次运行时限**：5 分钟是整队时间，单次发车是否有最长运行时间、能否中途复位重跑，未写明。
10. **电池更换**：封存时“可将电池带走”，但比赛中是否允许换电池、换电池是否重新计时，未写明。
11. **辅助传感器的边界**：超声波/TOF/IMU 可用成品，但光电组能否使用摄像头成品模块未明确；本方案不用摄像头。
12. **负压风扇限制**：允许增加，但尺寸、噪音、供电、是否计入投影未明确。
13. **赛道标记**：是否允许在赛道上放置信标/反光标记辅助定位，未写明；按不允许处理。
14. **零裁判比赛模式**：规则提到可能采用全国大学生智能汽车竞赛的“零裁判比赛模式”，具体流程未附，需赛前确认。
15. **封存后调参**：封存检查后是否允许通过按键修改参数、是否允许更换电池/传感器板，未写明。

> 处理原则：所有不明确项按“保守解释”设计，并在赛前向组委会/QQ 群确认；方案中把可能变化的量做成参数（环岛方向、停车距离、圈长），现场可调。

## 2. 核心任务拆解与得分关键点

### 2.1 任务链

```text
上电自检 → 等待发车 → 按键起跑 → 直线/折线循迹 → 十字直行 → 环岛绕行
→ 第二圈 → 发车线识别 → 过线后 20～35cm 减速停车 → 保持静止
```

### 2.2 关键点排序

| 优先级 | 关键点 | 原因 | 方案措施 |
| --- | --- | --- | --- |
| P0 | 不脱线、不失控 | 脱线即当次无效 | 18 路传感器 + 丢线 800ms 内停车 |
| P0 | 十字直行 | 错一次 +30s | 全黑模式识别 + 强制舵量置零 |
| P0 | 环岛通过 | 漏一次 +30s | 侧向传感器 + 宽度突变状态机 |
| P0 | 两圈后 50cm 内停车 | 失败 +20s | 里程计 + 发车线识别 + 距离闭环 |
| P1 | 自制驱动 −5s | 直接减时间 | 自制 TB6612 驱动板并留空板 |
| P1 | 平均速度 | 决定基础成绩 | 直线 0.9～1.1m/s，弯道 0.5～0.7m/s |
| P2 | 5 分钟内多次发车 | 提高取最好成绩的概率 | 快速复位、参数不丢、电池可换 |

### 2.3 目标指标

| 指标 | 目标值 | 说明 |
| --- | --- | --- |
| 单圈时间 | 18～25s | 按赛道总长 12～18m 估算，实测修正 |
| 两圈时间 | 40～55s | 含起步和弯道减速 |
| 罚时 | 0 | 十字/环岛/停车全部成功 |
| 停车位置 | 过线后 20～35cm | 规则窗口 0～50cm，留两侧余量 |
| 单次成功率 | ≥90% | 连续 100 次发车统计 |
| 5 分钟内有效发车 | ≥4 次 | 每次失败后 60s 内复位重发 |

## 3. 总体方案与关键指标

### 3.1 车体构型

- **驱动形式**：后轮双电机独立驱动 + 前部两个牛眼轮/万向轮，差速转向。
- **不采用舵机**：规则允许舵机，但双电机差速可以在 90° 折角处原地转向，结构更简单，少一个舵机电源和安装误差源。`firmware/drivers/servo/` 保留为后续扩展。
- **不采用麦克纳姆轮**：虽然规则允许，但需要 4 电机和更复杂的解算，51 资源不划算。
- **传感器布置**：车头前伸一排 16 路主传感器 + 左右各 1 路侧向传感器，整体宽度控制在 170mm 内。
- **重心**：电池放在后轴上方、尽量低；主控和驱动板放在中部；传感器板轻量化前伸。

### 3.2 关键指标

| 项目 | 指标 | 备注 |
| --- | --- | --- |
| 车体投影 | ≤260×180mm | 规则上限 297×210mm，留 ≥30mm 余量 |
| 整车质量 | ≤450g | 含电池 |
| 轮距/轴距 | 150mm / 120mm | 65mm 轮径 |
| 离地间隙 | 车架 8～10mm，传感器板下沿 7mm | 传感器板可调 4～10mm |
| 主传感器 | 16 路，10mm 间距，150mm 覆盖 | 黑线 18mm，至少 1～2 路压线 |
| 侧向传感器 | 左右各 1 路，±82mm，外偏 30° | 环岛入口/出口辅助 |
| 前瞻距离 | 传感器排中心到前轴 120mm | 兼顾 90° 折角与速度 |
| 安装高度 | 7mm（可调 4～10mm） | TCRT5000 反射式 |
| 扫描频率 | 200Hz（5ms） | 24 位移位读取约 100µs |
| 位置分辨率 | 原始 10mm，相邻加权后约 5mm | 数字阵列；更高分辨率需模拟灰度+ADC |
| PWM | 10kHz 时基，32 级，313Hz | 软件 PWM，双通道 |
| 循线控制 | 100Hz PD | 5ms 扫描、10ms 控制 |
| 速度环 | 50Hz PI（可选） | 编码器测速 |
| 直线速度 | 0.9～1.1m/s | 25GA-370 1:30 + 65mm 轮 |
| 弯道速度 | 0.5～0.7m/s | 按偏差自动降速 |
| 环岛速度 | 0.4～0.5m/s | 稳定优先 |
| 续航 | ≥45min | 3S 1500mAh |
| Flash 占用 | ≤6.0KB / 8KB | 不用 printf/浮点 |
| RAM 占用 | ≤300B / 512B | 不做全屏显存 |

## 4. 传感器方案

### 4.1 选型对比

| 方案 | 原理 | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- | --- |
| 数字红外反射阵列 | TCRT5000 + 比较器 + 移位寄存器 | 便宜、响应快、无需 ADC、适合 51 | 受环境光影响、10mm 量化、需要遮光 | **主方案** |
| 模拟灰度 + ADC | 光敏管模拟量 + ADC0832/ADC0809 | 分辨率高、可自适应阈值 | 需要 ADC 和多路复用、扫描慢、板子复杂 | 备选升级 |
| 激光 + 光敏 | 激光发射 + 接收 | 前瞻远、抗可见光 | 成本/安全/功耗、点式检测 | 不采用 |
| 摄像头 | 图像巡线 | 信息量大 | 51 算不动、成品模块合规风险 | 不采用 |
| 电磁 | 漆包线磁场 | 不受光照影响 | 光电赛道没有引导线 | 不适用 |

选择理由：STC89C52RC 没有 ADC，模拟灰度必须外挂 ADC 和多路复用，增加板面积与扫描时间；数字阵列用比较器把模拟量变成开关量，读取快、代码简单，配合 10mm 间距和加权插值足够跑 1m/s 量级。

### 4.2 推荐布局

```text
车头前方（俯视）
        左                                                    右
   SIDE_L  S0  S1  S2  S3  S4  S5  S6  S7  S8  S9 S10 S11 S12 S13 S14 S15  SIDE_R
          |<--------------------- 150mm，10mm 间距 --------------------->|
       外偏30°                                                          外偏30°
```

| 参数 | 取值 | 依据 |
| --- | --- | --- |
| 主通道数 | 16 | 覆盖 150mm，车宽 180mm；黑线 18mm 时至少 1～2 路有效 |
| 通道间距 | 10mm | 小于胶带最小宽度 15mm，保证不漏线；远小于邻道间距 200mm |
| 主阵列覆盖 | 150mm | 两侧各留 15mm，避免看到邻道 |
| 侧向通道 | 2 路 | 环岛入口/出口、赛道突然变宽 |
| 侧向位置 | ±82mm，外偏 30° | 在主阵列外侧，检测分支线 |
| 安装高度 | 7mm | TCRT5000 在 4～10mm 内可用，7mm 兼顾白布反光与黑线吸收 |
| 前瞻 | 120mm（排中心到前轴） | 90° 折角下不跨角看到另一段线；1m/s 时约有 120ms 反应时间 |
| 遮光 | 每对传感器加 5mm 黑色热缩管/遮光罩 | 抑制环境光和相邻通道串扰 |

### 4.3 电路实现

**单路传感器：**

- 发射端：TCRT5000 红外 LED，串联 180Ω 限流电阻到 5V，电流约 21mA。
- 接收端：光敏三极管集电极接 10k 上拉到 5V，发射极接地。
- 分压：接收端电压经 100k/100k 分压后送比较器，既保证比较器输入在 0～2.5V 的共模范围内，又不过度加载接收端。
- 比较器：LM339 四路一片，共 5 片；每路一个 10k 微调电位器设定阈值；输出开漏，10k 上拉到 5V；加 1M 正反馈形成约 10～50mV 回差。
- 备选：TLV1702/LMV393 轨到轨比较器，可省掉分压电阻。

> 关键点：LM339/LM393 的共模输入范围是 0～Vcc−1.5V，接收端直接给 4.8V 会超出范围，必须分压或换轨到轨比较器。

**数字读取：**

- 18 路数字量进 3 片 74HC165（24 位），级联后只用 3 根线：PL、CP、Q7。
- 165 放在传感器板上，缩短模拟走线；主板到传感器板用 2×5 IDC 排线，5V/GND 各用 2 芯。
- 级联顺序：165_A 输入 S0～S7，165_B 输入 S8～S15，165_C 输入 SIDE_L、SIDE_R 及 6 路备用；Q7_C→SER_B，Q7_B→SER_A，Q7_A→单片机，移出顺序为 A7…A0 → B7…B0 → C7…C0。
- 每片 165 的 VCC 脚加 0.1µF；PL/CP/Q7 串 100Ω，排线加 100nF 对地。
- 读取时序：PL 拉低 2µs 装载，拉高后连续 24 个 CP 脉冲移出；一次约 100µs。

**电源与功耗：**

- 18 路发射电流约 18×21mA≈380mA，5V 降压模块需 ≥2A。
- 传感器板入口加 100µF 电解 + 0.1µF 陶瓷。
- 若担心发热/串扰，可把发射端分成奇偶两组交替点亮（需要额外 2 个 GPIO 或 1 个三极管驱动），默认不做，先保证简单可靠。

### 4.4 标定与抗干扰

| 项目 | 方法 | 通过标准 |
| --- | --- | --- |
| 高度标定 | 在白色背景布上，分别在 4/6/8/10mm 测白/黑输出电压 | 7mm 时白黑压差 ≥2.0V，阈值余量 ≥0.8V |
| 阈值标定 | 每个电位器调到白/黑中点，OLED 显示 18 路状态 | 白底全 0、黑线全 1，边缘无抖动 |
| 环境光 | 日光灯、LED 灯、自然光三种条件各测 5 分钟 | 误判率 <1%，无持续翻转 |
| 邻道干扰 | 两条黑线间距 200mm，车放在一条线上 | 外侧通道不触发，或触发可被软件屏蔽 |
| 串扰 | 只遮住一路，观察相邻通道 | 相邻通道不误触发 |
| 长期漂移 | 连续通电 30 分钟，每 5 分钟复测 | 阈值漂移 <0.2V |

软件滤波：5ms 扫描一次，连续 3 次一致才确认；边缘通道做“邻道屏蔽”，当最外侧 1～2 路单独触发且中间全白时，视为邻道或噪点，不参与位置计算。

### 4.5 十字与环岛识别

**十字：**

- 特征：左右两半都出现大量黑线（各 ≥7 路），整体有效通道数 ≥14。
- 判定：连续 2 次扫描（10ms）满足 → 进入 CROSS 状态。
- 动作：舵量强制为 0，保持直行；直到有效通道数回落到 ≤8，退出 CROSS。
- 目的：避免在十字处被两侧线“拉偏”，也避免把十字误判成环岛。

**环岛：**

- 特征：一侧出现分支线（该半区有效通道突然增多），另一侧基本不变；侧向传感器触发；赛道有效宽度增加。
- 状态机：
  1. `NORMAL`：正常循迹。
  2. `ROUND_ENTER`：检测到单侧分支 + 侧向触发，减速到 0.4～0.5m/s，向环岛内侧打舵。
  3. `ROUND_IN`：以环岛内侧边线为参考，保持固定偏置；忽略外侧分支。
  4. `ROUND_EXIT`：侧向线消失、宽度恢复正常，回正并加速。
  5. `NORMAL`：冷却 300ms，防止重复触发。
- 方向参数 `ROUND_DIR`（左/右）做成配置项，现场按实际赛道确定；规则未明确绕行方向，必须在赛前确认。
- 区分十字与环岛：十字是左右对称全黑；环岛是单侧分支 + 侧向触发 + 持续时间长。折角是单侧变化但持续时间短，且没有侧向线，用持续时间/里程窗口区分。

> 环岛是最容易吃 +30s 的元素，建议单独做一个“环岛测试模式”：按键进入后只跑环岛，OLED 显示状态机和 18 路状态，便于快速调参。

### 5.2 驱动板

- 自制 PCB，板上只放 TB6612、去耦、端子、指示灯；铜层印队名/姓名/日期。
- STBY 用 10k 下拉到 GND：单片机上电/复位期间电机自动停止，这是安全关键。
- 逻辑 VCC 用 5V，VM 用电池 11.1V；TB6612 的 VM 最大 15V，3S 满电 12.6V 在范围内。
- 电机输出用 2P 接线端子，左右各一组；板上有 VM/GND/5V 测试点。
- 大二及以上必须自制；其他年级如果使用成品驱动，放弃 −5s，但建议仍自制。

### 5.3 差速控制策略

设基础占空比 `base`（0～32），PD 输出 `u`（−18～+18）：

```text
duty_L = clamp(base + u, 0, 32)
duty_R = clamp(base - u, 0, 32)
```

- 约定：传感器编号从左到右 S0→S15，位置误差 `e > 0` 表示线偏右 → 需要右转 → 左轮加速、右轮减速，即 `duty_L = base + u`、`duty_R = base - u`。
- 90° 折角：当 `|e|` 很大或单侧丢线时，允许内侧轮反转（`duty` 取负），实现原地转向；TB6612 支持正反转。
- 死区补偿：实测占空比 1～4 时电机不转，软件把 1～4 映射到 5，0 保持 0。
- 斜率限制：每 10ms 占空比变化不超过 2 级，减小电流冲击和齿轮冲击。
- 弯道降速：`base = BASE_FAST − (K_slow × |e| >> 4)`，并限制在 `[BASE_CORNER, BASE_FAST]`；`|e|` 超过阈值时直接取 `BASE_CORNER`。
- 差速上限：`|u| ≤ 18`，防止一侧占空比被压到 0 后失去修正能力。

### 5.4 编码器与测速

| 项目 | 取值 |
| --- | --- |
| 编码器线数 | 13 线/电机轴 |
| 减速比 | 1:30 |
| 输出轴每转脉冲 | 13×30 = 390 |
| 轮周长 | 65π ≈ 204.2mm |
| 每脉冲里程 | 204.2/390 ≈ 0.524mm |
| 1m/s 时脉冲频率 | 约 1910Hz/轮，双轮约 3820Hz |

- 50ms 速度环：`v_meas` 与目标速度比较，PI 输出 `base`；Ki 很小，避免 8 位机上积分饱和。
- 如果 CPU 吃紧，可把编码器降到 7 线，或只做单相计数、方向由电机指令给出；先保证循线环，再加速度环。

### 6.2 定时器与中断分配

| 资源 | 模式 | 用途 | 频率/周期 | 优先级 |
| --- | --- | --- | --- | --- |
| Timer0 | 模式 2（8 位自动重装） | 双通道软件 PWM 时基 | 10.017kHz（重装值 164） | 最高（PT0=1） |
| Timer1 | 模式 1（16 位） | 1ms 系统节拍 | 1ms（重装值 64615） | 低（PT1=0） |
| Timer2 | 波特率发生器 | 串口 9600/115200 | — | 无中断 |
| INT0 | 下降沿 | 左编码器 A 相 | ≤2kHz | 高（PX0=1） |
| INT1 | 下降沿 | 右编码器 A 相 | ≤2kHz | 高（PX1=1） |
| UART | 中断接收 | 调试/参数整定 | 9600 8N1 | 低 |

- PWM：`PWM_PERIOD = 32`，`PWM_FREQ = 10017/32 ≈ 313Hz`。占空比 0～32，分辨率 3.125%。
- 313Hz 是“10kHz 时基 / 32 级”的折中；若电机低速啸叫或抖动明显，可改为 16 级（625Hz）并重新整定，CPU 占用不变。
- Timer0 中断只做计数比较和引脚翻转，控制在 30 个机器周期以内；不要在里面做乘除。
- Timer1 1ms 中断只递增软件计数器和置标志，不做控制运算。
- 中断优先级只有两级：PWM 和编码器放高优先级，Timer1/UART 放低优先级；同一级内按自然顺序 INT0 > T0 > INT1 > T1 > UART > T2。
- 16 位共享变量（编码器计数、里程）读写时短时关中断，避免读到一半被中断打断。

### 6.3 主循环调度

| 周期 | 任务 | 预算 |
| --- | --- | --- |
| 1ms | 按键扫描、蜂鸣器节拍、看门狗喂狗 | <100 周期 |
| 5ms | 24 位传感器扫描、侧向传感器、状态滤波 | <600 周期 |
| 10ms | 位置计算、循线 PD、电机占空比更新 | <1200 周期 |
| 20ms | 速度环 PI、里程累计 | <2000 周期 |

### 6.4 巡线 PID 的 8 位实现

**位置计算（每 5ms）：**

```text
count = Σ w_i                 （i = 0..15，w_i ∈ {0,1}）
sum_i = Σ i × w_i
pos_q4 = (sum_i × 16) / count  （Q4，范围 0..240）
e_q4   = pos_q4 − 120          （中心 7.5×16）
```

- `count = 0`：丢线，进入丢线处理。
- `count ≥ 14`：十字候选。
- 两路相邻有效时，加权平均天然给出 0.5 个间距的插值；数字阵列的实际分辨率约 5mm，配合滤波和预测可稳定到 5mm 量级。若要 2～3mm 分辨率，需改用模拟灰度 + ADC 的备选方案。

**PD 计算（每 10ms）：**

```text
de_q4   = e_q4 − e_prev_q4
d_filt  = (3 × d_filt + de_q4) / 4        （一阶低通）
u       = (Kp_q8 × e_q4 + Kd_q8 × d_filt) >> 8
u       = clamp(u, −18, +18)
```

- `Kp_q8 = Kp × 256`，`Kd_q8 = Kd × 256`，全部整数运算。
- 初值建议：`Kp = 0.12`（Q8=31），`Kd = 0.45`（Q8=115），实测整定。
- 积分项默认关闭；如果直线长期偏一侧，加很小的 Ki（Q8≤4），并限制积分累加在 ±4 内。
- `d_filt` 限幅在 ±120，乘法用 `long`，避免 16 位溢出；`u` 限幅后再算占空比。
- 抗饱和：一侧占空比被限到 0 或 32 时，停止同方向积分。
- 死区：`|e_q4| < 4` 时 `u=0`，避免直线抖动。
- 输出斜率：每 10ms 占空比变化 ≤2 级。

**整定顺序：**

1. 低速（base=12）只加 Kp，增大到轻微左右摆动，回退 30%。
2. 加 Kd 抑制摆动，直到 90° 折角不超调。
3. 加弯道降速，观察不同 `|e|` 下的速度。
4. 最后加 50Hz 速度环；如果速度环引起抖动，先降 Ki 或暂时关闭。

## 7. 起跑、停车与异常保护

### 7.1 状态机

| 状态 | 进入条件 | 行为 | 退出 |
| --- | --- | --- | --- |
| `IDLE` | 上电/复位/按 STOP | 电机停，STBY 低，OLED 显示 READY | 长按 START 0.5s |
| `ARMED` | START 长按 | 3 声短鸣，1s 倒计时，参数自检 | 倒计时结束 |
| `RUN` | ARMED 结束 | 循线、元素识别、圈数累计 | 完成两圈/故障/超时 |
| `FINISH` | 第二圈完成过线（含起跑共第 3 次过线） | 减速、按里程停车、刹车保持 | 按 STOP |
| `FAULT` | 丢线/堵转/超时/低电压 | 电机停，蜂鸣器报警，OLED 显示原因 | 按 STOP 回 IDLE |

> `FAULT` 后如需收回车模，必须先示意裁判并获许可；按规则该次成绩无效，复位后可重新发车。
>
> 每次回到 `IDLE` 时清零圈数、里程和过线标志，保留已学习的 `L_lap` 和 PID 参数，方便 5 分钟内多次发车。

### 7.2 起跑逻辑

- 只用车上 `KEY_START`（P3.4）起跑，不用蓝牙/红外，避免“遥控”争议。
- 长按 500ms 才有效，防止误触；倒计时 1s 内松开则取消。
- 起跑后 300ms 内占空比从 0 斜坡升到 `BASE_FAST`，减少轮胎打滑和电流冲击。
- `RUN` 状态下忽略所有串口控制命令；蓝牙只允许读遥测，不允许写参数（或写参数需要先进入 `IDLE`）。

### 7.3 两圈计数与自主停车

**里程计：**

- 编码器脉冲累计，`1 pulse ≈ 0.524mm`。
- 总里程用 32 位变量，单圈里程用 16 位；按单圈 18m 估算约 3.4 万脉冲，单圈 16 位够用；两圈总里程约 6.9 万脉冲，必须用 32 位累计，防止溢出。

**发车线与圈数：**

- 默认车模停在发车线后方 20～50cm；起跑后第一次全黑过线记为“起跑过线”，不作为完成一圈。
- 规则要求连续两圈，因此完整流程是 3 次过线：起跑过线（开始计时）→ 第 1 圈完成 → 第 2 圈完成（进入停车）。
- 计数逻辑：
  - 起跑后 `cross_count=0`；第一次满足全黑且里程 <1.5m 的事件判为起跑过线，置 `start_crossed=1`，里程清零。
  - 之后每接受一次发车线事件，`lap_count++`；`lap_count==2` 时进入 `FINISH`。
  - 如果裁判要求车模停在线上或线后，第一次过线可能发生在 0m 附近或不存在；用 `START_MODE` 参数切换：0 时第一次过线算起跑，1 时第一次过线算第 1 圈。
- 发车线特征：有效通道 ≥14 的全黑模式；用 `L_lap` 里程窗口（±15%）过滤其他十字。
- 第一圈用“起跑过线 → 第一次圈过线”的里程学习 `L_lap`；第二圈用 `L_lap` 校验。
- 如果赛道有多个十字，用“里程窗口 + 全黑持续时间”区分：发车线通常是横跨赛道的单线，十字是交叉线，二者在全黑持续时间上可能不同；实测标定。
- 保守策略：如果无法可靠区分，用“里程计到达 2×L_lap”作为主判据，全黑事件作为校正。

**停车：**

- `lap_count==2`（第二圈完成过线，含起跑共第 3 次过线）后进入 `FINISH`，目标在过线后 25cm 停住（窗口 0～50cm）。
- 减速曲线：按剩余距离计算目标速度，或简单地把 `base` 每 10ms 减 1，直到 0；在 10～15cm 时短接电机两端刹车 100ms。
- 刹车后保持 2s，蜂鸣器长鸣一声，OLED 显示 STOPPED。
- 如果里程计显示已过线 45cm 仍未停，立即强制刹车（不超过 50cm）。
- 如果 2.2×L_lap + 2m 仍未识别到发车线，按超时停车，避免冲出赛道。

> 停车失败只 +20s，而脱线/冲出去可能判当次无效；所以“宁可早一点刹”在 0～50cm 窗口内是安全的，目标 25cm 留了前后余量。

### 7.4 异常保护

| 异常 | 检测 | 动作 |
| --- | --- | --- |
| 丢线 | 连续 150ms 无有效通道 | 保持上一次舵量，`base` 降到 50% |
| 长时间丢线 | 连续 800ms 无有效通道 | 立即停车，进 FAULT（规则 1s 判无效，提前停） |
| 堵转 | 占空比 ≥10 且 500ms 无编码器脉冲 | 停车，FAULT |
| 超时 | `RUN` 超过 120s | 停车，FAULT |
| 低电压 | 分压 + 比较器，P0.4 为低 | 先降速，低于 9.6V 停车 |
| 主循环卡死 | 主循环 200ms 未喂狗 | Timer1 中断里强制占空比 0 |
| 复位/上电 | — | STBY 10k 下拉，电机自动停；状态回 IDLE |
| 电机噪声复位 | 运行中复位 | 硬件去耦 + 电机 snubber + 独立地；软件上电先自检 |

说明：不同批次/头文件对 STC89C52RC 内部看门狗的支持不一致，本方案不把内部 WDT 作为安全依赖。软件“喂狗”只能强制停电机，不能复位；如果确认芯片支持 WDT，可启用；若要求更高，可外挂 TPS3823 一类看门狗芯片，但会增加板面积，默认不做。

## 附录 A 规则原文摘录（光电组相关）

> 以下为规则正文原文，未改动。

- “光电赛道是由宽度为 18mm±3mm 的黑色胶带组成环路，铺设在白色的背景布上。”
- “赛道由折线线段组成。折线夹角不小于 90°，折线长度不小于 10厘米。”
- “赛道包含直线、折线、十字交叉线、环岛等元素。环岛为六边形，六边形边长不小于 20厘米。两条相邻赛道之间的最小距离为 20 厘米。”
- “车模投影尺寸不得超过 29.7×21.0cm（A4纸大小），特殊情况由组委会另行裁定。”
- “若使用直插封装的主控芯片，核心板需自制。”
- “主板必须自制，其中：信息学院大二及以上学生需使用自制PCB参赛，其他学生可用洞洞板。”
- “光电组及电磁组的传感器电路板需自制，不得使用成品模块。”
- “车模需在指定赛道上连续运行两圈并自主停车。”
- “以车模上同一位置（一般为车头）越过发车线作为开始及停止计时的依据。”
- “车模脱离循迹线（光电组：所有车轮均位于循迹线同侧 1s以上）……则判定当次成绩无效，需重新发车。”
- “车模完成两圈运行后，在发车线 + 50cm（可越过发车线，不得提前停车）范围内自主停车视为有效停车。未能自主停车或手动停车的，比赛成绩 + 20s。”
- “每漏过一次环岛 或 每错误驶过一次十字，比赛成绩 + 30s。”
- “光电组使用自制电机驱动（需符合上述自制电路要求）参赛的，比赛成绩 – 5s。”
- “每队比赛时间为 五分钟，自进入赛道开始计时，发车次数不限。”
- “参赛选手在发车后的整个运行过程中不得接触车模，更不能遥控车模。”
