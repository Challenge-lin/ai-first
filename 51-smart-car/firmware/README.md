# firmware — 单片机固件

Keil C51（uVision）工程源码根目录，按「入口 → 应用 → 驱动 → 公共」分层。

- `project/`：Keil 工程文件（`.uvproj` / `.uvopt`）及编译配置，本阶段暂为空。
- `main/`：主程序入口 `main.c`，只做初始化、主循环与任务调度。
- `app/`：应用层业务逻辑，行驶模式、状态机、模式切换。
- `drivers/`：驱动层，每个外设一个子目录：
  - `motor/` 电机与 PWM，`tracking/` 红外循迹，`ultrasonic/` 超声波，
  - `remote/` 红外遥控与蓝牙，`servo/` 舵机云台，`display/` 显示屏，
  - `keys/` 按键，`buzzer_led/` 蜂鸣器与 LED。
- `common/`：延时、串口、缓冲区等通用工具，不放业务逻辑。
- `config/`：全局配置，集中定义引脚宏、阈值、周期与编译开关。
- `include/`：对外公共头文件，平铺存放，文件名与模块对应。
- `lib/`：芯片头文件与第三方库（如 `STC89C52.h`）。
- `build/`：编译中间文件与输出 `.hex`，仅本地使用，不纳入版本管理。

约定：`.c` 与 `.h` 同名成对；驱动层不调用应用层；跨层数据通过 `app` 传递；常量严禁散落硬编码。
