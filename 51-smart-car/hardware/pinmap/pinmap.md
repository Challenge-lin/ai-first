## 4. 传感器板 74HC165 级联与位映射

### 4.1 级联

```text
单片机 P1.2 (Q7) ← QH_A ← 165_A ← SER_A ← QH_B ← 165_B ← SER_B ← QH_C ← 165_C
PL  = P1.0，三片并联
CP  = P1.1，三片并联
CLK INH（脚 15）全部接 GND
QH'（脚 7）悬空
```

移出顺序：A7…A0 → B7…B0 → C7…C0。为了令 bit0 对应 S0，传感器按下表接到 165 的 D7→D0（即 H→A）。

读取结果建议按 24 位处理：

| 位 | 含义 |
| --- | --- |
| bit0～bit7 | S0～S7 |
| bit8～bit15 | S8～S15 |
| bit16 | SIDE_L |
| bit17 | SIDE_R |
| bit18～bit23 | 备用 |

> 实际位序以“单通道点亮测试”为准：遮住 S0，读到的应为 bit0=1；若相反，在 `firmware/config/` 用位序宏反转，不要改硬件。

### 4.3 165 外围

- 每片 VCC 脚加 0.1µF，尽量靠近芯片。
- PL、CP、Q7 各串 100Ω，排线入口加 100nF 对地。
- 165_C 的未用输入接 GND，不要悬空。
- 传感器板入口加 100µF 电解 + 0.1µF 陶瓷。
- 排线长度控制在 25cm 内，远离电机线；与电机线交叉时尽量垂直。

## 6. 硬件注意事项

1. **P0 上拉**：P0 作输入必须外接 10k 上拉（P0.0、P0.1、P0.3、P0.4 已标注）；P0 作输出为开漏，需要上拉才能输出高电平。
2. **P3.4/P3.5**：分别是 T0/T1 引脚，但 Timer0/Timer1 使用内部时钟，引脚可作普通 I/O；P3.4 已用作 START。
3. **P3.6/P3.7**：WR/RD，仅在访问外部存储器时有效；本方案不使用外部存储器，可作普通 I/O，默认留备用。
4. **UART 共用**：P3.0/P3.1 同时接 ISP 和 HC-05，必须用 J8 的两组跳线分别切换；下载时拔掉两组跳线，避免 HC-05 的 TX 干扰下载握手。
5. **STBY 下拉**：P2.6 到 GND 接 10k，保证复位/上电期间 TB6612 处于待机，电机不转。
6. **EA 上拉**：脚 31 经 10k 接 VCC，使用内部 ROM。
7. **复位**：10µF 从 VCC 到 RST，10k 从 RST 到 GND，按键并在电容两端；复位走线远离电机线。
8. **晶振**：11.0592MHz 与 22pF×2 尽量靠近脚 18/19，底部铺地，不走长线。
9. **核心板边界**：核心板只放 MCU 座、晶振、复位、去耦、EA 上拉；所有 I/O 接插件在主板上，符合“I/O 从自制主板引出”的规则。
10. **铜层标识**：主板、传感器板、驱动板在铜层印“队名 + 队员姓名 + 制作时间”，各留一块同版本空板备查。
11. **3.3V 模块电平**：HC-05 的 TX 和 OLED 的 SDA/SCL 若为 3.3V 逻辑，高电平约 3.3V，接近 5V 单片机的 3.5V 输入门限；优先选带电平转换的 5V 模块，或在 TX/SDA/SCL 加 74HC125/分压。HC-05 的 RX 若不耐 5V，MCU 的 TX 需 1k/2k 分压。
